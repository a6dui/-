# CS2 News Channel Bot (UA)

Проєкт для автоматичного новинного каналу по Counter-Strike 2:
- регулярно перевіряє RSS-стрічки;
- відправляє в Telegram тільки хайпові новини (фільтр по score);
- не дублює вже відправлені новини (SQLite);
- стиль повідомлень — більш паблік/мемний українською (без обов'язкових посилань/джерела).
- відправляє нові новини в Telegram-бота;
- не дублює вже відправлені новини (SQLite);
- текст і службові повідомлення — українською.

## Швидкий запуск (автономний)

1. Встановити залежності:
```bash
npm install
```

2. Запустити:
```bash
node server.js
```

У цьому режимі бот працює **автономно без Telegram**: збирає новини та зберігає їх у `database.sqlite`.

## Запуск з Telegram

Створи `.env` в корені проєкту:

```bash
BOT_TOKEN="<telegram_bot_token>"
CHAT_ID="<telegram_chat_id>"
POLL_INTERVAL_MINUTES=10
HTTP_TIMEOUT_MS=15000
PORT=3000
```

Потім запусти:
```bash
node server.js
```

## Доступні endpoints

- `GET /health` — стан сервісу, інтервал опитування та ознака автономного режиму.
- `GET /cs2newsua-banner.svg` — шапка каналу.
