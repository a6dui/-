# CS2 News Channel Bot (UA)

Проєкт для автоматичного новинного каналу по Counter-Strike 2.

## Почему у тебя не запускалось

По скриншоту ты запускал команды в домашней папке `~`, а не в папке проекта.
Из-за этого и были ошибки:
- `Could not read package.json`
- `Cannot find module '/Users/.../server.js'`

## Запуск в 3 шага (самый простой)

1. Перейди в папку проекта:
```bash
cd /путь/к/папке/проекта
```

2. Один раз сделай запуск-скрипт исполняемым:
```bash
chmod +x start.sh
```

3. Запусти:
```bash
./start.sh
```

Скрипт сам:
- проверит, что ты в нужной папке;
- поставит `npm install` (если нужно);
- запустит `node server.js`.

## Настройка Telegram через папку `env`

1. Создай файл на основе шаблона:
```bash
cp env/.env.example env/.env
```

2. Открой `env/.env` и заполни:
- `BOT_TOKEN`
- `CHAT_ID`

3. Снова запускай:
```bash
./start.sh
```

> Если `BOT_TOKEN`/`CHAT_ID` пустые — бот всё равно работает автономно (собирает новости в SQLite без отправки в Telegram).

## Проверка

Открой:
- `http://localhost:3000/health`

Если видишь JSON с `ok: true` — бот работает.
